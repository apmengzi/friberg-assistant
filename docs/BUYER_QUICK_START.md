# 买家快速开始

1. 安装商业扩展并打开弗一把多人页面。
2. 激活页点击“复制设备码”并发送给卖家。
3. 收到许可证后完整复制，从 `FRIBERG1.` 开始，不能漏字符。
4. 粘贴后点击“激活并进入”。
5. 激活成功后悬浮窗会显示许可证编号、到期时间、剩余时间、软件版本和题库/适配版本。

许可证只适用于生成它时的设备码。清除扩展数据、删除后重装、换浏览器或换电脑可能产生
新设备码。许可证按自然时间到期，不按实际打开插件的时长暂停计时。

常见错误：

- “签名无效”：许可证内容被漏复制或修改；
- “设备不匹配”：许可证不是针对当前设备码生成；
- “已经到期”：本机时间达到许可证到期时间；
- “系统时间明显倒退”：恢复正确系统时间后点击“重新检查”；
- “软件版本不支持”：安装卖家提供的兼容版本。
