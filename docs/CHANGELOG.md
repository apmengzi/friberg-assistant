# Changelog

## 0.9.3 hotfix 2026-07-31

- 按原网页实际 2 秒猜测间隔修正提交排队，并读取页面显示的剩余冷却时间；
- 冷却期间点击“提交当前猜测”会持续排队，倒计时结束后只点击原网页按钮一次；
- BO3 换小局时综合“第 N 局”标记、棋盘清空、行数回退和待识别状态重建会话；
- 监听 React 的纯文字节点更新，并直接读取“我的猜测 0/8”作为新小局信号；
- 增加 350ms 轻量状态巡检，恢复被浏览器或 React 合并掉的换局事件；
- 修复赢下上一小局后“随机首猜并填入”仍保持灰色的问题；
- 扩展与 ScriptCat 共用上述修复，并增加浏览器回归测试。

## 0.9.2 Paid Beta

- 新增离线 Ed25519 签名许可证；
- 新增 128 位随机安装实例和带校验位的设备码；
- 新增设备绑定、版本范围、生效/到期检查和基础时间回退检测；
- 新增激活页、设备码复制、明确错误原因；
- 悬浮窗新增许可证编号、到期时间、剩余时间和组件版本；
- 许可证失效后停止监听、求解、填入和提交；
- 商业构建移除在线服务器依赖、localhost、ScriptCat和卖家工具；
- 新增商业 ZIP 自动安全审计、文件清单和 SHA-256；
- 个人免激活版继续保持 0.9.1。
