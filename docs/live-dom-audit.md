# 公开页面只读 DOM 审计

审计日期：2026-07-28。

## 已确认的静态事实

部署产物的本地快照 [work/game.index.html](../work/game.index.html) 指向 Vite/React 模块；[work/game.deployed.js](../work/game.deployed.js) 包含 `/multi`、`/multi/room` 和独立 realtime 模块的路由/加载字符串。这只能证明公开部署的技术形态，不能证明某个实时页面当前的元素选择器、反馈行结构或网络事件。

## 未伪造的部分

对 `https://shnlfriberg.online/multi/` 的首次只读加载在本环境超时；Web 缓存也没有返回可验证的实时 DOM。期间没有执行输入、点击、提交、读取 localStorage/IndexedDB、订阅网络流量或尝试取得答案。

因此本项目没有把任何猜测出来的 `.class`、React Fiber、WebSocket payload 或页面文字当成公开页面适配器。公开页面内容脚本在来源策略为 `public` 时会在挂载提示后立刻停止；它不加载题库矩阵、不枚举棋盘、不写入输入框，也不触发按钮。

## 后续可审计的接入条件

如需公开页面的“只读推荐”适配器，必须先在用户可见的真实页面完成以下审计，并把证据写入本项目：

1. 可见的自己的反馈行有稳定、非隐私的 DOM 标识；
2. 七个字段、数值箭头、胜负状态可从页面可见节点严格读取；
3. 不读取答案、React 内部状态、存储或网络消息；
4. 对至少一局人工提交的可见行回放，候选集与本地严格求解器一致；
5. 保持公开来源的 `canAct = false`，不允许任何填入或提交。

在这些条件满足前，截图求解器仍是公开站点的可用路径；全自动只在本地镜像或可验证的、所有参与者同意的私人测试页中启用。
