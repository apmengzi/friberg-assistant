# 商业版安装说明

版本：0.9.2 Paid Beta

1. 解压 `friberg-assistant-commercial.zip`。
2. 打开 `edge://extensions` 或 `chrome://extensions`。
3. 开启“开发人员模式”。
4. 选择“加载解压缩的扩展”，选择最外层直接含有 `manifest.json` 的文件夹。
5. 打开 `https://shnlfriberg.online/multi`。
6. 首次出现激活页后点击“复制设备码”，把设备码发给卖家。
7. 将卖家返回的完整 `FRIBERG1.…` 许可证粘贴到激活页并点击“激活并进入”。

买家不需要启动任何本地服务器。商业版不应连接 `127.0.0.1` 或 `localhost`。

## 更新

为保留安装实例标识和许可证，优先把新版文件覆盖进原扩展文件夹，然后在扩展管理页面点击
“重新加载”。不要先删除扩展。若删除扩展、清除扩展数据或改为加载另一个文件夹，设备码
可能改变，需要卖家决定是否重新签发。
