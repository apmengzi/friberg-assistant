# 验证记录（2026-07-28）

## 自动回归

执行：

```powershell
node .\tests\run-regression.js
```

结果：通过。

覆盖项：

- 本地游戏题库为 646 条、全部可规范化并保留游戏赛区。
- 国家灰色会排除整个游戏赛区；例如 frozen 的斯洛伐克灰色会排除 torzsi 的匈牙利（同为欧洲），但保留 woxic 的亚太赛区。

- supplied frozen → torzsi → woxic → aizy 四行历史回放得到唯一合法集合：`jee`、`tiger`、`z4kr`；`aizy` 不在其中。
- 非法的“战队黄色”会被拒绝而不是偷偷放宽条件。

## 全题库契约审计

执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\run-full-pool-contract-audit.ps1
```

结果：四个确定性分片全部通过，覆盖完整的 646 × 646 = 417,316 个猜测—真实答案组合，以及 84,175 个不同的颜色/箭头反馈分区。每个分区都断言：求解器返回的候选集合与独立 oracle 的答案集合完全相同；每个猜测者的全绿属性分区也都断言已猜昵称会被排除。

这个 oracle 依据公开游戏后端的 [gameService.ts](https://github.com/shnlfriberg/csgofriberg/blob/main/server/src/services/gameService.ts) 独立实现，不调用 `solver.js` 来决定正确颜色。审计还发现并覆盖了 36 个“七项属性相同、昵称不同”的实际猜测情形，因此全绿属性不会被误判为直接获胜。

## 截图颜色复核

对用户提供的四行源截图按页面同一套颜色阈值和七列色块几何进行像素复核，aizy 最近行读为：战队灰、国家灰、年龄灰、位置灰、冠军绿、参赛灰、状态绿。也就是说，绿色的 Major 冠军格会保持绿色，不会再被昵称列或相邻灰格挤位。

## 交付限制

本次验证没有自动提交任何游戏猜测，也没有自动操作目标对战网站。HLTV 全站历史资料不是当前 646 人游戏题库的一部分；扩展数据必须独立存储，不能改变严格截图求解的游戏字段。
