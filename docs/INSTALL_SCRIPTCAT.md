# ScriptCat 安装

要导入的脚本是：

`C:\Users\30369\Documents\Codex\2026-07-27\https-chatgpt-com-share-6a6635c6-2c34\dist\friberg-assistant.user.js`

它与 `friberg-assistant-scriptcat.user.js` 内容相同；前者文件名更短，适合直接导入。

1. 在 Edge 安装并启用 ScriptCat。
2. 在 ScriptCat 中选择导入本地脚本，选择上面的 `.user.js` 文件。
3. 确认脚本已启用，匹配规则为 `https://shnlfriberg.online/multi*`。
4. 打开 `/multi` 或匹配后的 `/multi/room`；右侧会显示“弗一把助手”。

ScriptCat 与扩展使用同一份 646 人题库、严格求解器和 DOM 反馈适配器。两者都不会自动循环提交；只有你明确点击“提交当前猜测”且安全校验通过时，才会点击游戏原网页的提交按钮。

不需要关闭 Edge 安全功能。若页面没有悬浮窗，先确认 ScriptCat 的脚本开关、匹配规则和当前 URL，再刷新页面。

具体操作见 [真实对局使用方法](USAGE_REAL_SITE.md)。
