# 已知限制

- 0.9.2 是 Paid Beta，不是稳定版 1.0。
- 离线许可证不能远程撤销，不能可靠统计实际使用小时，也不能承诺绝对防破解。
- 浏览器扩展源码对买家可见；压缩只能提高普通修改成本。
- 删除扩展、清除扩展数据或加载到新路径可能改变设备码。
- 系统时间回退检测属于基础防护，恢复整套浏览器数据快照仍可能绕过。
- 当前主要实测环境是 Edge；Chrome 的商业扩展现场对局仍需继续验证。
- 弗一把网页 DOM 改版后可能暂时无法识别，此时应暂停并导出诊断。
- 无法识别反馈颜色、箭头或自己的棋盘时，插件不会继续求解或提交。
- 商业版不包含 ScriptCat 用户脚本。
