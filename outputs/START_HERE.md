# 弗一把 · Scout Console

这是本地严格截图版：把弗一把结果表截图粘贴进来，它会读取最近一行的绿 / 黄 / 灰反馈，再用全部历史反馈做逻辑交集。

## 打开

- [打开工具首页](../index.html)
- [使用说明与数据格式](../README.md)
- [本地 646 人题库](../data/players.game-646.json)
- [严格规则说明](../docs/game-rules.md)
- [回归验证](../tests/run-regression.js)

双击 [start.bat](../start.bat)，或在工具目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

然后访问 `http://127.0.0.1:4173/`。

## 推荐流程

1. 在弗一把截图，回到工具按 `Ctrl+V`，或点“导入截图”。
2. 在“这行猜的是谁？”选择这一行已经猜过的昵称。
3. 确认 7 个反馈色格；昵称列没有反馈颜色。必要时校正数字箭头，点击“应用颜色”。
4. 只会显示同时满足所有反馈的合法候选；点候选卡“复制昵称”，回弗一把手动提交。

本地题库来源于弗一把公开完整版数据；工具只在本地辅助推理，不读取或操控对战页面。
- 每次“应用颜色”都会加入当前回合的严格约束；可以用 `Ctrl+Z` 撤销上一猜。推荐下一猜只会从合法候选中选择。
- 本地核心是弗一把公开的 646 人题库，不是 HLTV 全站历史 profile。HLTV 扩展字段不能覆盖游戏求解字段。
